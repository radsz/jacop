JaCoP properties that can be controlled by option -D in java command. For example, java -Dmax_edge_find_size=200 controls the maximal size of the task list in the cumulative constraint to use edge-finding algorithm.

Most of these properties exist to measure or switch off one technique; the
defaults are the settings that measured best. Boolean properties take true or
false; "on/off" properties take the words given. A property is read once, when
the class that uses it is loaded, so it must be given on the java command line
(for MiniZinc, add it to the java command in the fzn-jacop script, or set it
in JAVA_TOOL_OPTIONS), not set later in the program.

Example with the FlatZinc front end:

  java -Djacop.lcg=off -Dorg.jacop.lp.cuts=false -cp jacop.jar org.jacop.fz.Fz2jacop model.fzn


Properties:

Java specific:
==============
- max_edge_find_size: use edge finder in the cumulative constraints if
  it contains less tasks than this number; default 100. This applies
  to Cumulative constraint only; CumulativeUnary runs its unary rules
  (detectable precedences, not-first/not-last, edge finding) for any
  number of tasks.

- sub_circuit_scc_pruning: use pruning method based on strongly
  connected components; default true (one of sub_circuit_* must be true).

- sub_circuit_dominance_pruning: use pruning method based on node
  domination in graphs; default false (one of sub_circuit_* must be true).

- jacop.values.cliques: Values (MiniZinc nvalue) reads at the root the
  pairs of its variables that other constraints force to differ (x != y,
  alldifferent, x = y + t or |x - y| = t with t never 0, x = y + c with
  c != 0) and bounds the number of values from below by a clique of
  them; default true.

- sub_circuit_dominance_skip: the largest number of calls the
  dominance pruning of Subcircuit is skipped after a call that pruned
  nothing (the skip doubles each time); default 32.

- layered_graph_engine: propagation algorithm of the layered-graph
  constraints (Regular, MDD): auto, counters (trailed counters of
  alive edges, as in Gecode / MDD4R) or support_search (depth first
  search for supports, as in mddc); default auto (counters, switching
  to support search when that is faster).

- jacop.asserts.enabled: run the internal consistency checks that
  replaced Java assert statements; default false. For debugging only,
  it slows the solver down.

Constraints (core):
===================
- org.jacop.constraints.LinearIntDom.sumset: how LinearIntDom finds
  the supports of an equality: auto (sumsets of partial sums when
  estimated cheaper than enumeration), always (sumsets whenever within
  their limit) or off; default auto.

- org.jacop.exactCover.inclusion: the DL+ rule of ExactCover; default
  true.

- jacop.convexAllocation.exact: the largest number of variables for
  which ConvexAllocation computes the bounds exactly; above it uses
  Lagrangian reduced costs; default 64.

- jacop.differenceCycles.budget: the most arc relaxations of the first
  Bellman-Ford pass of DifferenceCycles; default 50000000.

- jacop.cumulative.optionalRules: overload check and edge finding over
  optional tasks (resource use 0 or positive) in CumulativeUnary;
  default false.

- jacop.cumulative.presenceFit: a task that may use nothing gets use 0
  where it fits nowhere (UnaryTimetable); default true.

- org.jacop.weightedCompletion.prefixRows: on a resource of capacity
  above 1, WeightedCompletion tightens the fluid bound with the rows of
  the prefixes of Smith's order, each also bounded by the earliest
  completion of its tasks; default true.

- org.jacop.weightedCompletion.prefixWork: the work (tasks times time
  points) of one bound above which the prefix rows are left out;
  default 40000.

- org.jacop.weightedCompletion.prefixOthers: the prefix rows also in the
  bound of the other tasks that limits each start (one more pass per
  task); default false.

- org.jacop.weightedCompletion.weakReasons: under --lcg, the reasons of
  the parallel bound lower the minima of the free starts towards their
  root values as far as the propagation still follows; default true.

- org.jacop.weightedCompletion.reasonRounds: the halvings tried when
  weakening such a reason; default 4.

- org.jacop.lateCount.releases: LateCount bounds the late tasks from
  the best origin, with the processing before it relaxed, instead of
  from the earliest start of all; default true.

- org.jacop.lateCount.reasons: under --lcg, LateCount explains its
  pruning with the bounds its relaxation reads (late tasks, on time
  tasks, minima lowered towards their root values as far as the bound
  still holds, the maximum of late) instead of every atom of its
  variables; default true.

- org.jacop.unaryEarlinessTardiness.blocks: the most blocks of time
  slots of a machine in the assignment bound of
  UnaryEarlinessTardiness; slots are grouped into blocks of equal
  length above it; default 64.

- org.jacop.unaryEarlinessTardiness.trial: the solves after which a
  machine of UnaryEarlinessTardiness whose bound never beat the exact
  minima of its tasks is no longer solved (0 never stops, and turns off
  forcedRound and workPerPropagation too); default 200.

- org.jacop.unaryEarlinessTardiness.forcedRound: the exact solves of
  UnaryEarlinessTardiness, forced in search because a cheap upper
  estimate says the node could fail, after which, if none of them
  failed, only one in 16 is done until one fails; default 500.

- org.jacop.unaryEarlinessTardiness.workPerPropagation: the work (inner
  steps of the transportation solver, about a nanosecond each) the
  exact solves of UnaryEarlinessTardiness in search may take per
  propagation of the store; a forced solve is skipped while they took
  more, which keeps the cost of the bound to a share of the search and
  the search deterministic (0 no budget); default 1000.

- org.jacop.unaryEarlinessTardiness.filter: reduced-cost filtering of
  the start bounds in UnaryEarlinessTardiness: a start bound is removed
  when restricting the task's window raises the dual bound of its
  machine above the maximum of the cost; default true.

- org.jacop.unaryEarlinessTardiness.lagrange: iterations of the
  subgradient search, at the root, of the Lagrangian multipliers of the
  precedences given to UnaryEarlinessTardiness (the FlatZinc front end
  gives it the precedences it finds between its tasks); 0 relaxes the
  precedences without multipliers; default 30.

- org.jacop.diffn.dff: dual feasible functions in the area check of
  Diffn: 0 off, 1 gated (only when the rectangles fill at least half
  of the space, Steinberg's theorem), 2 always; default 1.

- org.jacop.diffn.energetic: energetic reasoning on the strips across
  each dimension of Diffn: 0 off, 1 with the dual feasible functions,
  2 with the plain energy only; default 0.

- org.jacop.diffn.areaReasons: under LCG a failure of the Diffn area
  check is explained by the rectangles in the window only; default
  true.

- org.jacop.diffnk.reasons: under LCG DiffnK explains its pruning and
  failures by the boxes of the rule (false: generic reasons); default
  true.
- org.jacop.rewrite: constraints replace themselves by simpler ones
  during search when the current domains allow it (their prunings are
  recorded as those of the original for LCG); default true.
- org.jacop.rewrite.element: ElementVariableFast with a fixed index
  becomes an equality; default true.
- org.jacop.rewrite.reified: a reification or implication whose Boolean
  is fixed becomes its nested constraint (or its negation), as Gecode
  rewrites its reified propagators; default true.
- org.jacop.linearIncrementalTerms: an imposed LinearInt with at least
  this many terms keeps its bounds incrementally instead of rescanning
  them, 0 for never; default 200.
- org.jacop.netflow.generalArcs: NetworkFlow decides residual arcs of
  any capacity by shortest paths when it can, not only arcs of capacity
  one; false probes every such arc instead; default true.
- org.jacop.netflow.shortestPaths: NetworkFlow probes the arcs left
  after the shortest paths by successive shortest paths instead of
  network simplex pivots; default true.
- org.jacop.maxClique.renumber: MaxCliqueBound tries to cover the
  vertices beyond the limit by re-colouring (MCS); default true.
- org.jacop.maxClique.maxsat: MaxCliqueBound tries to cover them by
  MaxSAT failed-literal reasoning (Li and Quan); default true.
- org.jacop.maxClique.degeneracy: MaxCliqueBound colours the vertices in
  the minimum width order of MCS instead of by decreasing degree;
  default true.
- org.jacop.maxClique.force: MaxCliqueBound sets the one vertex left
  uncovered to 1; default true.
- org.jacop.maxClique.greedyStarts: the starting vertices of the greedy
  clique of MaxCliqueBound; default 100.
- jacop.sequenceMdd.skip: the most calls of SequenceMdd skipped after
  calls that pruned nothing; default 63.
- jacop.sequenceMdd.replayNodes: the largest circuit whose SequenceMdd
  pruning LCG explains by replaying the constraint; a larger one gives
  the generic reason at once; default 32.
- org.jacop.table.binaryBitSpan: the most values between the least and
  the largest value of a column of a BinaryBitTable; default 4096.
- org.jacop.geost.reasons: under LCG, Geost explains its pruning and
  failures by covering the swept region (else by replay); default true.
- org.jacop.floats.minReduction: the smallest relative reduction of a
  float domain that is applied; smaller narrowings are skipped, 0
  applies every one; default 0.
- org.jacop.search.free.domWdegScan: free search dom/wdeg scans all
  variables at each decision instead of selecting incrementally (both
  give the same variable); default false.

flatzinc compiler specific:
===========================
Solver modes (defaults of command line options):

- jacop.lcg: lazy clause generation, on or off; default on. Changes
  the default of --lcg, for example to run the FlatZinc test suites,
  whose expected outputs were recorded without LCG.

- jacop.presolve: presolve mode, off, on or check; default off.
  Changes the default of --presolve.

- jacop.presolve.level: presolve rule level, fast, medium or
  exhaustive; default exhaustive. Changes the default of
  --presolve-level.

- jacop.presolve.probe: probing in presolve, off, shave or sac;
  default sac. Changes the default of --probe.

- jacop.presolve.tabling: presolve replaces small groups of
  constraints by tables; default false. Same as --presolve-tabling.

- jacop.components: solve before search the independent components
  the objective does not depend on, on or off; default on. Changes the
  default of --components.

- jacop.components.budget: the time, in milliseconds, the searches of
  all those components may take together; default 2000.

- jacop.symmetry: =presolve breaks symmetries only when presolve is
  on, as the FlatZinc test suites do; by default symmetries are broken
  with or without presolve (see --symmetry).

- org.jacop.fz.symmetry.schreierSims: =on posts Schreier-Sims cuts
  x_b <= x_j over the orbits of the stabilizer chain of the variable
  symmetries, where the lex-leader constraints do not imply them; =count
  only counts them (symmetrySchreierSimsCuts); =off skips them; default on.

- org.jacop.fz.symmetryTime: the most time, in milliseconds, of the
  automorphism search of symmetry detection (also at most 1/20 of the
  time left); default 1000.

- org.jacop.fz.symmetrySets: =false keeps every set variable in place
  in symmetry detection (a colour of its own), as before; by default
  symmetries may exchange set variables when the search annotation
  branches on set variables. Default true.

- org.jacop.fz.symmetryEncoded: =false turns off the second search for
  value symmetries, through set variables and overlapping value
  groups, that runs when the plain value spaces give none. Default
  true.

- fz_system_timer: if =true use System.nanoTime instead of ManagementFactory
  timer for threads, otherwise use thread time.

- jacop.fz.timeOutGrace: milliseconds after the time-out (-t) before
  the watchdog stops the run; default 1000.

Cumulative, disjunctive and diffn:

- fz_cumulative_use_unary: during constraints generation in flatzinc
  compiler use CumulativeUnary for tasks that have resource capacity
  greater than half of the cumulative capacity bound; default=false

- fz_cumulative_use_disjunctions: during constraints generation in
  flatzinc compiler pairwaise task disjunction constraints for all
  pairs of tasks that have sum of resource capacities greater than the
  cumulative capacity bound; default=false

- fz_cumulative_ef: use edge finding in cumulative constraints
  (up to max_edge_find_size tasks); default=false, since time-table
  edge finding with time-table disjunctive reasoning solved more
  cumulative benchmarks without it

- fz_cumulative_quad_ef: use the quadratic edge finding instead of
  the O(kn log n) one; by default chosen from the number of tasks and
  of distinct resource uses, always quadratic for variable tasks

- fz_cumulative_heef: use horizontally elastic edge finding (Gingras
  and Quimper, IJCAI 2016) in cumulative constraints; default=false

- fz_cumulative_ttef: use time-table edge finding in cumulative
  constraints; default=true

- fz_cumulative_ttdr: use time-table disjunctive reasoning in
  cumulative constraints; default=true

- fz_cumulative_adaptive: skip time-table edge finding and time-table
  disjunctive reasoning in cumulative constraints while they prune
  nothing, running them less often the longer they stay idle;
  default=true

- fz_cumulative_overload: use the overload check in cumulative
  constraints when edge finding is off; default=true

- fz_cumulative_optional_overload: use the overload check and edge
  finding that make optional tasks absent; default=true for
  cumulative with optional tasks and false for disjunctive with
  optional tasks

- fz_cumulative_variable_basic: post CumulativeBasic (time-tabling
  only), as before, for cumulative constraints with variable
  durations or resource uses; default=false

- fz_cumulative_flow: add the preemptive flow check HornFlow to
  cumulative constraints: unit (only when all tasks use one unit),
  true (all) or false; default=false

- org.jacop.fz.optionalAsUse: post optional tasks on a unary resource
  with their presences as resource uses: lcg (only under lazy clause
  generation), true (always) or false (never, CumulativeUnaryOptional);
  default lcg.

- org.jacop.fz.interDistance: a cumulative of tasks with one length
  and one resource use becomes InterDistance or MultiInterDistance:
  true (replace), add (post next to the cumulative) or false;
  default true.

- org.jacop.fz.multiCumulative: cumulative constraints over the same
  tasks share one time-table sweep (MultiCumulative), without LCG and
  presolve only; default true.

- org.jacop.fz.presolveCumulative: presolve rule for cumulative
  resources (dual fixing); default true.

- fz_diffn_cumulative: diffn also gets a cumulative per axis;
  default=true

- fz_diffnk_projection: projection check of diffn_k (cross-sections
  of the boxes must fit); default=false

- fz_diffnk_slices: slice check of diffn_k; default=false

Lazy clause generation (--lcg):
===============================
Search of the LCG solver:

- jacop.lcg.branching: decisions outside the search annotation:
  activity (most active integer variable), literals (the SAT solver's
  own decisions), auto (literals, but activity from 1000 conflicts to
  the first solution) or alternate (runs take turns at each restart);
  default activity.
- jacop.lcg.value: value of an activity decision: split (lower half),
  max or min; default split.
- jacop.lcg.lastConflict: last-conflict branching; default true.
- jacop.lcg.bump: which variables a conflict bumps for activity
  branching: seen (every integer variable whose atoms the analysis
  met) or learnt (only the learnt clause's); default seen.
- jacop.lcg.booleansFirst: activity branching on 0/1 variables
  first; default true.
- jacop.lcg.late: none, or defined (the defined variables and the
  Booleans of redundant constraints are branched on last); default
  defined.
- org.jacop.fz.lcgDomWdegLimit: above this many default search
  variables, the default search of a model without a search annotation
  branches in input order instead of dom/wdeg, whose scan over all of
  them at every decision costs too much; default 50000.
- jacop.lcg.lpGuideRoot: the activity runs of fixed search follow
  the root solution of the linear relaxation, not its last one;
  default true.
- org.jacop.lns.shift: large neighbourhood search (-f) also uses shift
  neighbourhoods: the tasks of cumulative, unary and disjunctive
  resources that start in a window of time are free, those after it
  may start earlier than in the best solution (start <= its value) and
  the rest keep their values; default false (saeling 2026 j0050_m003
  makespan 1333 instead of 1350 at 600 s, but worse on rcpsp-wet-
  diverse, cgt and multi-agent-graph-coverage).
- jacop.lcg.stableForGood: after the first 1000 conflicts in focused
  mode, stay in stable mode (far fewer restarts); default true.
- jacop.lcg.fullFixpoint: run the store to its fixpoint before the
  clauses propagate again; false returns to the clauses after each
  pruning; default true.
- jacop.jasat.jump: share of the time of the SAT solver (without LCG or
  assumptions) given to feasibility-jump local search at rephasing
  points, 0 for none; default 0.1. jacop.jasat.jumpDebug prints each
  call; default false.

Core-guided phase (free search, --lcg -f):

- jacop.lcg.coreTrial: the share of the core-guided phase that
  measures its rate when the objective's root bound is above the
  cores' lower bound; default 0.1.
- jacop.lcg.coreSkip: skip the core-guided phase when its probe's
  rate cannot raise the bound to the root bound; default true.
- jacop.lcg.coreProbeSkip: skip the rest of the core-guided phase
  when its probe stopped without a solution of its own and branch and
  bound found one; default true.
- jacop.lcg.coreNoSolution: the core phase gives its time to branch
  and bound when it has no solution of its own by this share of its
  time, 0 turns it off; default 0.33.
- jacop.lcg.coreStall: the share of the run's work after the core
  phase's start from which the phase also gives its time to branch and
  bound when its bound, at three times its rate over the second half
  of the phase, would not meet the best solution; 0 turns it off;
  default 0.1.
- jacop.lcg.coreRestore: after the core phase, branch and bound
  starts from the activity before it; default true.
- jacop.lcg.coreAnySolution: the old test, any best solution counts,
  also one of branch and bound before the phase; default false.
- jacop.lcg.workPerMs: the solver work per millisecond of a time limit,
  from which the phases take their shares, so that a run repeats
  with the same limit whatever the load of the machine; default 2000.
- jacop.virtualClock: lazy clause generation reads a virtual clock that
  counts its work (jacop.lcg.workPerMs per millisecond) instead of the
  system clock, for the time limit, phase shares, neighbourhood runs,
  probes and the check of LCG's speed, so that benchmark runs repeat;
  default false.
- jacop.virtualClock.wallFactor: under jacop.virtualClock, the watchdog
  that ends a run waits this many times the time-out; default 10.
- jacop.lcg.workPerCall: the work of one consistency call, in
  propagated literals; default 3.
- jacop.lcg.clockSlack: a phase also stops at this many times its
  share of the time left; default 1.5.

Root probing (off by default):

- jacop.lcg.probe: root probing before LCG search, for at most this
  share of the time left; default 0 (off).
- jacop.lcg.probe.early: probe before the linear relaxation is built,
  with a solver of its own, so that --lp has the probed domains and the
  clique rows of the probing conflicts; default false.
- jacop.lcg.probe.delay: probe between runs of branch and bound, once
  this share of the time limit has passed, instead of before the
  search; default 0 (before the search).
- jacop.lcg.probe.domain: also probe each value of the other variables
  with at most this many values; default 64.
- jacop.lcg.probe.barren: stop when this share of the budget found no
  fact; default 0.25.
- jacop.lcg.probe.conflicts: the most probing conflicts kept for the
  clique rows; default 100000.
- jacop.lcg.probe.only: stop after probing and print its statistics, to
  measure its reach; default false.
- jacop.lcg.probe.lp: with probe.only, the root bound of a relaxation
  built again after probing: none, facts (probed domains) or cliques
  (also the conflicts as rows); default none.

Literals and clauses:

- jacop.lcg.literalBudget: the solver variables in use above which a
  value removal without a literal of its own is kept out of the solver;
  default one per 1 KB of the maximum heap.
- jacop.lcg.releaseLiterals: release literals created only to push a
  bound (Chuffed's lazy literals); default true.
- jacop.lcg.liftLiterals: cite a weaker existing literal for a lifted
  bound; default true.
- jacop.lcg.holeLimit: domains with more values than this keep only
  their bounds in the atomic trail; default 10000.
- jacop.lcg.reasonKeep: reasons of up to this many literals stay as
  clauses; default 3.
- jacop.lcg.semantic: semantic minimisation of learnt clauses;
  default true.
- jacop.lcg.semanticUip: semantic UIPs in conflict analysis; default
  true.
- jacop.lcg.graphClauses: Regular and MDD constraints become clauses
  of the solver; default true.
- jacop.lcg.clauses: constraints given to the SAT solver as clauses
  in place of propagators: none, all, or a comma-separated list of
  class names (for example FzXeqC,Reified,Implies,SumBool); default
  none. A constraint over the objective's definition stays a propagator.
  The name counter gives the 0/1 sums (LinearInt, SumBool, LinearBool,
  SumInt, Count, AtMost, AtLeast) to a unary counter alone and keeps
  them unsplit in the FlatZinc front end, which can slow down a model
  whose long sums are then not encoded.
- jacop.lcg.clauses.limit: the most clauses of one constraint; default
  256.
- jacop.lcg.clauses.dom: the largest domain of its variables, one
  variable of a longer constraint may be wider; default 64.
- jacop.lcg.clauses.counter: the most clauses of the unary counter of
  a 0/1 sum outside a reification; default 20000.
- jacop.lcg.clauses.boolArity: the most unfixed variables of a
  constraint as clauses, and the largest domain of any; default 256.
- jacop.lcg.clauses.debug: print each constraint tried and its clause
  count; default false.
- jacop.lcg.pureClauseLiterals: under free search, a model whose
  variables are all 0/1 and whose constraints all became clauses leaves
  every decision to the SAT solver; default true.
- org.jacop.lcg.alldiffCover: cover clauses for an all-different whose
  variables have as many values as there are variables; default true.
- org.jacop.lcg.alldiffCoverLimit: the most (variable, value) pairs
  those clauses may use; default 16384.

Explanations:

- jacop.lcg.lift: reasons lifted, bounds weakened as far as the

- jacop.lcg.replay: replayed explanations; default true.
- jacop.lcg.replayGroups: reasons with more groups than this get the

- jacop.lcg.replayShare: the most consistency calls the replays of a

- jacop.lcg.flowShare: the largest share of the time the flow

- jacop.lcg.cardinalityCounts: counting reasons of GCC tried before

- jacop.lcg.binpackingCounts: Binpacking explanations cover the

- jacop.lcg.cumulativePairs: cumulative explains starts by pairs of

- jacop.lcg.windowLift: cumulative window reasons keep only the energy

- jacop.lcg.optionalExplain: explanations of CumulativeOptional and

- jacop.lcg.unaryExplain: CumulativeUnary explains the bounds of its

- jacop.lcg.reservoirExplain: Reservoir explanations; default true.

Linear conflict analysis:

- jacop.lcg.linear: cut-based conflict analysis of linear failures:

- jacop.lcg.linearSteps, jacop.lcg.linearTerms: the most steps and

- jacop.lcg.linearLimit: the most learnt sums imposed; default 20000.
- jacop.lcg.linearKept: for a literal set by a kept clause, the

  default true.
- jacop.lcg.linearClauses: explanations over 0/1 variables as linear

- jacop.lcg.linearRows: the analysis also uses the rows of the

Proofs (--proof):

- jacop.lcg.proofTerms: the most terms of the OPB model of a proof;

- jacop.lcg.proofTrace: name the constraint behind each explanation

- jacop.virtualClock.propagationsPerMs: under jacop.virtualClock, the

- jacop.lcg.probe.cap: the most ms root probing takes whatever its

- jacop.lcg.alldiffClauses: permutations become clauses (pairwise

- jacop.lcg.alldiffClauses.limit: the most clauses of one all different

  more than the average pivot, with the factorization counted this
  many times its work, 0 for a fixed limit of 100 updates; default 1.
- org.jacop.jalp.refactorUpdates: the most updates before a
  refactorization; default 1000.
- org.jacop.jalp.refactorFill: the most nonzeros of the updates, as a
  multiple of the factors; default 2.
- org.jacop.jalp.refactorMin: the fewest updates before a
  refactorization; default 10.
- org.jacop.jalp.hyper: the share of the steps a solve may reach for
  the hypersparse (Gilbert-Peierls) solve; default 0.1.
- org.jacop.jalp.crash: crash basis of the first solve: off, eq,
  ranged or all; default off.
- org.jacop.jalp.crashPivot: a crash pivot must be at least this
  share of the largest entry of its column; default 0.9.
- org.jacop.jalp.crashZeroCost: crash only with columns without cost;
  default false.
- org.jacop.jalp.crashGuard: drop a crash basis with more dual
  infeasibilities than the slack basis; default true.
- org.jacop.jalp.crashExactWeights: exact steepest-edge weights of the
  crash basis; default false.
- org.jacop.jalp.presolve: presolve the first solve of a JaLP problem
  and start the whole problem from the postsolved basis; default true.
- org.jacop.jalp.presolveRows: presolve only problems with at least
  this many rows; default 1.
- org.jacop.jalp.presolveParallel: in the presolve, merge parallel rows
  and parallel columns (Andersen and Andersen 1995, sections 3.4 and
  3.6); default true.
- org.jacop.jalp.presolveTrace: print the sizes and the reductions of
  each presolve to standard error; default false.
- org.jacop.jalp.main: modes of the stand-alone LP solver (LpMain), a
  comma separated list of primal and reobjective; default empty.
- org.jacop.jalp.linearScore: the leaving row by gap^1.2 / weight
  instead of gap^2 / weight: "auto" (default) on LPs shaped like
  multicommodity networks, "on", "off".
- org.jacop.jalp.presolveForcing: presolve removes forcing rows; default
  true.
- org.jacop.jalp.presolveDominated: presolve fixes columns dominated
  over the bounds of the duals; default true.

Decomposition bound:
====================

- org.jacop.fz.decomposition: before search, bound the objective by a
  Dantzig-Wolfe decomposition of the model into blocks linked by
  counting (CountValuesBounds) and linear constraints, with column
  generation over a JaLP master and pricing problems solved in the
  store or, for hard blocks, in a copy with lazy clause generation; the
  bound is certified in integer arithmetic. Default false.
- org.jacop.fz.decomposition.share: the share of the time limit (-t) the
  bound may take; default 0.2.
- org.jacop.fz.decomposition.ms: the time, in milliseconds, it may take
  without a time limit; default 60000.
- org.jacop.fz.decomposition.priceMs: the time, in milliseconds, of one
  pricing problem at most; default 2000.
- org.jacop.fz.decomposition.storeMs: the time, in milliseconds, of a
  pricing search in the store before a block that can be copied goes to
  lazy clause generation; default 300.
- org.jacop.fz.decomposition.pivots: the pivots of each simplex of one
  master solve at most; default 20000.
- org.jacop.fz.decomposition.smoothing: the weight of the best
  multipliers in the duals the pricing problems get (Wentges
  smoothing); default 0.5.
- org.jacop.fz.decomposition.large: the variables of a block at least,
  of which there must be two; default 10.
- org.jacop.fz.decomposition.trace: print the blocks and every column
  generation iteration to standard error; default false.
- org.jacop.fz.decomposition.primal: under free search (-f), start from
  the columns of the master (an integer solution of the restricted
  master, else the heaviest column of each block) and give the blocks to
  large neighbourhood search (kind BLOCKS); default true.
- org.jacop.fz.decomposition.primalMs: the time, in milliseconds, of the
  search for an integer solution of the restricted master; default 1000.

Debugging:
==========
- jacop.lcg.check: check every LCG explanation (ExplanationChecker);
  default false.
- jacop.lcg.minimality: every this many explanations one is minimised
  and measured, 0 for none; default 0.
- jacop.jasat.check: check the propagation invariants of the SAT solver
  at every fixpoint; default false.
- jacop.ls.debug: print why local search rejects moves; default false.
- jacop.ls.verify: check the incremental state of local search (sums,
  counters, windows, element selections, followers) against values
  computed afresh after every step; default false.
- tmp.lattice: print the pruning of LinearEqualities by residue
  classes; default false.
- org.jacop.search.free.domWdegCheck: check each incremental dom/wdeg
  selection of free search against one made by a scan; default false.
- jacop.dominance.debug: print the candidates the dominance rule checks;
  default false.
- jacop.lcg.tableClauses.debug: print each table tried as clauses;
  default false.
- org.jacop.fz.pureClauses.dump=file: write the CNF of a pure clause
  model in DIMACS format.
- org.jacop.lp.sourceStats: relaxations keep per-source row statistics
  (with --search-statistics); default false.
- jacop.lcg.mine=file: a research tool: classify learnt clauses by the
  constraints whose scope covers their variables, counts written to the
  file.
- jacop.lcg.mine.budget, jacop.lcg.mine.size, jacop.lcg.mine.nodes: the
  share of the time spent mining, the largest clause mined and the nodes
  of each implication check; default 0.5, 24 and 5000.
