JaCoP properties that can be controlled by option -D in java command. For example, java -Dmax_edge_find_size=200 controls the maximal size of the task list in the cumulative constraint to use edge-finding algorithm.

Most of these properties exist to measure or switch off one technique; the
defaults are the settings that measured best. Boolean properties take true or
false; "on/off" properties take the words given. A property is read once, when
the class that uses it is loaded, so it must be given on the java command line
(for MiniZinc, add it to the java command in the fzn-jacop script, or set it
in JAVA_TOOL_OPTIONS), not set later in the program.

Example with the FlatZinc front end:

  java -Djacop.lcg=off -Dorg.jacop.lp.cuts=false -cp jacop.jar org.jacop.fz.Fz2jacop model.fzn


Properties:

Java specific:
==============
- max_edge_find_size: use edge finder in the cumulative constraints if
  it contains less tasks than this number; default 100. This applies
  to Cumulative constraint only; CumulativeUnary runs its unary rules
  (detectable precedences, not-first/not-last, edge finding) for any
  number of tasks.

- sub_circuit_scc_pruning: use pruning method based on strongly
  connected components; default true (one of sub_circuit_* must be true).

- sub_circuit_dominance_pruning: use pruning method based on node
  domination in graphs; default false (one of sub_circuit_* must be true).

- jacop.values.cliques: Values (MiniZinc nvalue) reads at the root the
  pairs of its variables that other constraints force to differ (x != y,
  alldifferent, x = y + t or |x - y| = t with t never 0, x = y + c with
  c != 0) and bounds the number of values from below by a clique of
  them; default true.

- sub_circuit_dominance_skip: the largest number of calls the
  dominance pruning of Subcircuit is skipped after a call that pruned
  nothing (the skip doubles each time); default 32.

- layered_graph_engine: propagation algorithm of the layered-graph
  constraints (Regular, MDD): auto, counters (trailed counters of
  alive edges, as in Gecode / MDD4R) or support_search (depth first
  search for supports, as in mddc); default auto (counters, switching
  to support search when that is faster).

- jacop.asserts.enabled: run the internal consistency checks that
  replaced Java assert statements; default false. For debugging only,
  it slows the solver down.

Constraints (core):
===================
- org.jacop.constraints.LinearIntDom.sumset: how LinearIntDom finds
  the supports of an equality: auto (sumsets of partial sums when
  estimated cheaper than enumeration), always (sumsets whenever within
  their limit) or off; default auto.

- org.jacop.exactCover.inclusion: the DL+ rule of ExactCover; default
  true.

- jacop.convexAllocation.exact: the largest number of variables for
  which ConvexAllocation computes the bounds exactly; above it uses
  Lagrangian reduced costs; default 64.

- jacop.differenceCycles.budget: the most arc relaxations of the first
  Bellman-Ford pass of DifferenceCycles; default 50000000.

- jacop.cumulative.optionalRules: overload check and edge finding over
  optional tasks (resource use 0 or positive) in CumulativeUnary;
  default false.

- jacop.cumulative.presenceFit: a task that may use nothing gets use 0
  where it fits nowhere (UnaryTimetable); default true.

- org.jacop.weightedCompletion.prefixRows: on a resource of capacity
  above 1, WeightedCompletion tightens the fluid bound with the rows of
  the prefixes of Smith's order, each also bounded by the earliest
  completion of its tasks; default true.

- org.jacop.weightedCompletion.prefixWork: the work (tasks times time
  points) of one bound above which the prefix rows are left out;
  default 40000.

- org.jacop.weightedCompletion.prefixOthers: the prefix rows also in the
  bound of the other tasks that limits each start (one more pass per
  task); default false.

- org.jacop.weightedCompletion.weakReasons: under --lcg, the reasons of
  the parallel bound lower the minima of the free starts towards their
  root values as far as the propagation still follows; default true.

- org.jacop.weightedCompletion.reasonRounds: the halvings tried when
  weakening such a reason; default 4.

- org.jacop.unaryEarlinessTardiness.blocks: the most blocks of time
  slots of a machine in the assignment bound of
  UnaryEarlinessTardiness; slots are grouped into blocks of equal
  length above it; default 64.

- org.jacop.unaryEarlinessTardiness.trial: the solves after which a
  machine of UnaryEarlinessTardiness whose bound never beat the exact
  minima of its tasks is no longer solved (0 never stops, and turns off
  forcedRound and workPerPropagation too); default 200.

- org.jacop.unaryEarlinessTardiness.forcedRound: the exact solves of
  UnaryEarlinessTardiness, forced in search because a cheap upper
  estimate says the node could fail, after which, if none of them
  failed, only one in 16 is done until one fails; default 500.

- org.jacop.unaryEarlinessTardiness.workPerPropagation: the work (inner
  steps of the transportation solver, about a nanosecond each) the
  exact solves of UnaryEarlinessTardiness in search may take per
  propagation of the store; a forced solve is skipped while they took
  more, which keeps the cost of the bound to a share of the search and
  the search deterministic (0 no budget); default 1000.

- org.jacop.unaryEarlinessTardiness.filter: reduced-cost filtering of
  the start bounds in UnaryEarlinessTardiness: a start bound is removed
  when restricting the task's window raises the dual bound of its
  machine above the maximum of the cost; default true.

- org.jacop.unaryEarlinessTardiness.lagrange: iterations of the
  subgradient search, at the root, of the Lagrangian multipliers of the
  precedences given to UnaryEarlinessTardiness (the FlatZinc front end
  gives it the precedences it finds between its tasks); 0 relaxes the
  precedences without multipliers; default 30.

- org.jacop.diffn.dff: dual feasible functions in the area check of
  Diffn: 0 off, 1 gated (only when the rectangles fill at least half
  of the space, Steinberg's theorem), 2 always; default 1.

- org.jacop.diffn.energetic: energetic reasoning on the strips across
  each dimension of Diffn: 0 off, 1 with the dual feasible functions,
  2 with the plain energy only; default 0.

- org.jacop.diffn.areaReasons: under LCG a failure of the Diffn area
  check is explained by the rectangles in the window only; default
  true.

- org.jacop.diffnk.reasons: under LCG DiffnK explains its pruning and
  failures by the boxes of the rule (false: generic reasons); default
  true.

flatzinc compiler specific:
===========================

Lazy clause generation (--lcg):
===============================
Search of the LCG solver:

- jacop.lcg.branching: decisions outside the search annotation:
  activity (most active integer variable), literals (the SAT solver's
  own decisions), auto (literals, but activity from 1000 conflicts to
  the first solution) or alternate (runs take turns at each restart);
  default activity.
- jacop.lcg.value: value of an activity decision: split (lower half),
  max or min; default split.
- jacop.lcg.lastConflict: last-conflict branching; default true.
- jacop.lcg.bump: which variables a conflict bumps for activity
  branching: seen (every integer variable whose atoms the analysis
  met) or learnt (only the learnt clause's); default seen.
- jacop.lcg.booleansFirst: activity branching on 0/1 variables
  first; default true.
- jacop.lcg.late: none, or defined (the defined variables and the
  Booleans of redundant constraints are branched on last); default
  defined.
- org.jacop.fz.lcgDomWdegLimit: above this many default search
  variables, the default search of a model without a search annotation
  branches in input order instead of dom/wdeg, whose scan over all of
  them at every decision costs too much; default 50000.
- jacop.lcg.lpGuideRoot: the activity runs of fixed search follow
  the root solution of the linear relaxation, not its last one;
  default true.
- jacop.lcg.stableForGood: after the first 1000 conflicts in focused
  mode, stay in stable mode (far fewer restarts); default true.
- jacop.lcg.fullFixpoint: run the store to its fixpoint before the
  clauses propagate again; false returns to the clauses after each
  pruning; default true.

Core-guided phase (free search, --lcg -f):

- jacop.lcg.coreTrial: the share of the core-guided phase that
  measures its rate when the objective's root bound is above the
  cores' lower bound; default 0.1.
- jacop.lcg.coreSkip: skip the core-guided phase when its probe's
  rate cannot raise the bound to the root bound; default true.
- jacop.lcg.coreNoSolution: the core phase gives its time to branch
  and bound when it has no solution of its own by this share of its
  time, 0 turns it off; default 0.33.
- jacop.lcg.coreRestore: after the core phase, branch and bound
  starts from the activity before it; default true.
- jacop.lcg.coreAnySolution: the old test, any best solution counts,
  also one of branch and bound before the phase; default false.
- jacop.lcg.workPerMs: the solver work per millisecond of a time limit,
  from which the phases take their shares, so that a run repeats
  with the same limit whatever the load of the machine; default 2000.
- jacop.lcg.workPerCall: the work of one consistency call, in
  propagated literals; default 3.
- jacop.lcg.clockSlack: a phase also stops at this many times its
  share of the time left; default 1.5.

- jacop.lcg.releaseLiterals: release literals created only to push a
  bound (Chuffed's lazy literals); default true.
- jacop.lcg.liftLiterals: cite a weaker existing literal for a lifted
  bound; default true.
- jacop.lcg.holeLimit: domains with more values than this keep only
  their bounds in the atomic trail; default 10000.
- jacop.lcg.reasonKeep: reasons of up to this many literals stay as
  clauses; default 3.
- jacop.lcg.semantic: semantic minimisation of learnt clauses;
  default true.
- jacop.lcg.semanticUip: semantic UIPs in conflict analysis; default
  true.
- jacop.lcg.graphClauses: Regular and MDD constraints become clauses
  of the solver; default true.
- jacop.lcg.clauses: constraints given to the SAT solver as clauses
  in place of propagators: none, all, or a comma-separated list of
  class names (for example FzXeqC,Reified,Implies,SumBool); default

  The name counter gives the 0/1 sums (LinearInt, SumBool, LinearBool,

- jacop.lcg.clauses.limit: the most clauses of one constraint; default

- jacop.lcg.clauses.dom: the largest domain of its variables, one

- jacop.lcg.clauses.counter: the most clauses of the unary counter of

- jacop.lcg.clauses.boolArity: the most unfixed variables of a
  constraint as clauses, and the largest domain of any; default 256.
- jacop.lcg.clauses.debug: print each constraint tried and its clause
  count; default false.
- jacop.lcg.pureClauseLiterals: under free search, a model whose

- org.jacop.lcg.alldiffCover: cover clauses for an all-different whose

- org.jacop.lcg.alldiffCoverLimit: the most (variable, value) pairs

- jacop.lcg.linearSteps, jacop.lcg.linearTerms: the most steps and
  terms of one analysis; default 64 and 200.
- jacop.lcg.linearLimit: the most learnt sums imposed; default 20000.
- jacop.lcg.linearKept: for a literal set by a kept clause, the
  analysis uses the constraint whose explanation that clause is;
  default true.
- jacop.lcg.linearClauses: explanations over 0/1 variables as linear
  rows of their clause; default true.
- jacop.lcg.linearRows: the analysis also uses the rows of the
  constraints that are not linear (their linearizations); default
  true.

Proofs (--proof):

- jacop.lcg.proofTerms: the most terms of the OPB model of a proof;
  default 20000000.
- jacop.lcg.proofTrace: name the constraint behind each explanation
  in a comment and write each conflict clause as a step (debugging);
  default false.

Linear relaxation (LP):
=======================
Rows and encodings:

- org.jacop.lp.linearize: add the rows of constraints that are not
  linear relations; default true.
- org.jacop.lp.smallExtra: such rows are kept when they move the bound,
  find infeasibility or are at most this many; default 100.
- org.jacop.lp.valueColumns: value encodings over LP-only columns;
  default true.
- org.jacop.lp.valueColumnsDomain, org.jacop.lp.valueColumnsMax: the
  largest domain encoded and the most columns per model; default 128
  and 20000.
- org.jacop.lp.valueEncodings: value encodings of counting,
  all-different and element constraints; default true.
- org.jacop.lp.valueEncodingsDomain, org.jacop.lp.valueEncodingsMax:
  the largest domain encoded and the most columns per model; default
  64 and 20000.
- org.jacop.lp.flowEncodings: flow model of the layered graphs of
  Regular and MDD; default true.
- org.jacop.lp.binpackingRows: assignment rows of bin packing among
  the value encodings; default false.
- org.jacop.lp.tableCliques: clique rows of binary tables; default
  true.
- org.jacop.lp.tableCliqueArity: the largest table, in variables,
  whose projections on pairs give conflicts; default 6.
- org.jacop.lp.tableCliqueDomain: the largest domain that gets value
  columns; default 16.
- org.jacop.lp.tableCliqueLiterals, org.jacop.lp.tableCliqueRows: the
  most columns and rows of the conflict graph; default 8000 and 20000.
- org.jacop.lp.tableEncodings: rows of the convex hull of tables over
  tuple columns; default true.
- org.jacop.lp.tableTupleColumns, org.jacop.lp.tableTuples: the most
  tuple columns over all tables and the most tuples of one table;
  default 20000 and 2000.
- org.jacop.lp.pairCliques: conflicts of pairs of 0/1 literals merged
  into clique rows; default true.

Cuts:

- org.jacop.lp.cuts: MIR cuts at the root; default true.
- org.jacop.lp.cutRounds, org.jacop.lp.cutsPerRound: rounds and cuts
  per round; default 5 and 50.
- org.jacop.lp.reduceCuts: a cut with weights too large or too far
  apart is scaled down instead of dropped; default true.
- org.jacop.lp.slackGomory: root Gomory cuts over the rows and their
  slacks (false: MIR of the aggregate of the rows alone); default true.
- org.jacop.lp.capacityCuts: rounded capacity cuts of Routes at the
  root; default true.
- org.jacop.lp.capacityRounds: their rounds; default 50.
- org.jacop.lp.multistarCuts: multistar cuts over the same sets;
  default true.
- org.jacop.lp.combCuts: blossom and comb cuts of Routes over the
  mandatory customers, in the slots the capacity cuts leave; true or
  false for every Routes; by default only for Routes without a
  capacity (travelling salesman tours).
- org.jacop.lp.combSearch: blossom and comb cuts also in search (by
  default only at the root); default false.
- org.jacop.lp.capacitySearch: capacity and multistar cuts also in
  search; default true.
- org.jacop.lp.capacitySearchCuts: the most cuts per separation in
  search; default 10.
- org.jacop.lp.energyCuts: energy cuts of cumulative resources at the
  root; default true.
- org.jacop.lp.alldiffCuts: Hall cuts of all-different constraints at
  the root, for an objective; default true.
- org.jacop.lp.alldiffVariants: the same cuts, with value copies, for
  all-different with exceptions (alldifferent_except_0) and global
  cardinality constraints (GCC, CountValues, CountValuesBounds);
  default true.
- org.jacop.lp.alldiffSearch: Hall cuts also in search, every few LP
  solves; default false.
- org.jacop.lp.alldiffSearchCuts: the most Hall cuts per separation in
  search; default 10.
- org.jacop.lp.treeCuts: generalized subtour elimination cuts of the
  forests of Tree and Path (MiniZinc tree, dtree, path, dpath) at the
  root, for an objective; a model with them also takes all its other
  rows into the relaxation; default true.
- org.jacop.lp.treeRounds: their rounds; default 200.

Row pool and lazy rows:

- org.jacop.lp.pool: rows of other constraints and cuts leave the
  simplex after poolAge optimal solves in which they are inactive;
  default true.
- org.jacop.lp.poolAge: default 100.
- org.jacop.lp.poolExtra: rows the root trial does not keep stay in
  the pool instead of being dropped; default false.
- org.jacop.lp.poolCuts: cuts of a round that does not move the bound
  stay in the pool; default false.
- org.jacop.lp.lazyBatch, org.jacop.lp.lazyRounds, org.jacop.lp.lazyAge:
  lazy rows: the most rows added per round, the rounds per solve and
  the optimal solves a row stays inactive before it leaves; default
  50, 100 and 100.

Work limits:

- org.jacop.lp.work: the most work credit of the relaxation in search
  (tableau entries); default 20000000.
- org.jacop.lp.rootWork: the work budget of the root solve; default
  1000000000.
- org.jacop.lp.rootPivots: the most pivots of the first solve; default
  20000.
- org.jacop.lp.workPerCall: the credit earned by each consistency
  call; default 4096.
- org.jacop.lp.pruneDiscount: a solve that only tightens bounds pays
  1/this of its work; default 16.
- org.jacop.lp.idle, org.jacop.lp.maxPeriod: the solve period doubles
  after this many solves that deduce nothing, up to maxPeriod; default
  32 and 4096.
- org.jacop.lp.maxTableau: the largest dense tableau, rows times
  columns; default 4000000.
- org.jacop.lp.maxNonzeros: the most nonzeros of the rows of the
  sparse simplex; default 4000000.

Simplex choice and bases:

- org.jacop.lp.sparseRows: the dense simplex for relaxations below
  this many rows, the sparse one (JaLP) from it on; -1 always dense;
  default 100.
- org.jacop.lp.sparseMaxRows, org.jacop.lp.sparseMaxColumns: the
  largest relaxation the sparse simplex is chosen for; default 25000
  and 30000.
- org.jacop.lp.sparseRootWork: the work budget of a root solve of the
  sparse simplex; default 4000000000.
- org.jacop.lp.sparseRootSeconds: the most time of such a solve, in
  seconds; default 3.
- org.jacop.lp.sparseCost: the work of the sparse simplex in units of
  a dense tableau entry; default 1.
- org.jacop.lp.keepBases: keep the basis of each level of the branch
  and restore it after restarts and long backjumps; default true.
- org.jacop.lp.basisJump: the levels a jump must span to restore a
  kept basis; default 2.
- org.jacop.lp.maxBases: the most kept bases; default 32.
- org.jacop.lp.denseBasisDepth: the dense simplex keeps the bases of
  levels at most this far below the first solve, -1 none; default 3.
- org.jacop.lp.basisProbation: the calls after a jump during which the
  basis the deeper node left is used; default 1000.
- org.jacop.lp.restartFromRoot: a solve at a restart starts from the
  root basis; default true.
- org.jacop.lp.restartSolves: solve again at the root level whenever
  the objective bound improved; default false.
- org.jacop.lp.restartCuts: new cut rounds in those solves; default
  true.
- org.jacop.lp.rootReducedCosts: root reduced-cost fixing; default
  true.
- org.jacop.lp.givenDuals: duals for the costs as given (false: for
  the perturbed costs); default true.
- org.jacop.lp.exact: remove the perturbation at the end of every solve
  (JaLP's clean-up); default false.
- org.jacop.lp.clean: clean the combination of a certificate (drop
  multipliers of a missing side, divide by gcd); default true.

JaLP sparse simplex:
====================
- org.jacop.jalp.perturbation: relative size of the cost
  perturbation; default 1e-6.
- org.jacop.jalp.boundPerturbation: relative bound perturbation after
  a run of degenerate pivots; default 5e-6.
- org.jacop.jalp.maxScaleExponent: the largest exponent of a scale
  factor; default 20.
- org.jacop.jalp.refactorWeight: refactorize when the last solves cost
  more than the average pivot, with the factorization counted this
  many times its work, 0 for a fixed limit of 100 updates; default 1.
- org.jacop.jalp.refactorUpdates: the most updates before a
  refactorization; default 1000.
- org.jacop.jalp.refactorFill: the most nonzeros of the updates, as a
  multiple of the factors; default 2.
- org.jacop.jalp.refactorMin: the fewest updates before a
  refactorization; default 10.
- org.jacop.jalp.hyper: the share of the steps a solve may reach for
  the hypersparse (Gilbert-Peierls) solve; default 0.1.
- org.jacop.jalp.crash: crash basis of the first solve: off, eq,
  ranged or all; default off.
- org.jacop.jalp.crashPivot: a crash pivot must be at least this
  share of the largest entry of its column; default 0.9.
- org.jacop.jalp.crashZeroCost: crash only with columns without cost;
  default false.
- org.jacop.jalp.crashGuard: drop a crash basis with more dual
  infeasibilities than the slack basis; default true.
- org.jacop.jalp.crashExactWeights: exact steepest-edge weights of the
  crash basis; default false.
- org.jacop.jalp.presolve: presolve the first solve of a JaLP problem
  and start the whole problem from the postsolved basis; default true.
- org.jacop.jalp.presolveRows: presolve only problems with at least
  this many rows; default 1.
- org.jacop.jalp.presolveParallel: in the presolve, merge parallel rows
  and parallel columns (Andersen and Andersen 1995, sections 3.4 and
  3.6); default true.
- org.jacop.jalp.presolveTrace: print the sizes and the reductions of
  each presolve to standard error; default false.
- org.jacop.jalp.main: modes of the stand-alone LP solver (LpMain), a
  comma separated list of primal and reobjective; default empty.

Debugging:
==========
- jacop.lcg.check: check every LCG explanation (ExplanationChecker);
  default false.
- jacop.lcg.minimality: every this many explanations one is minimised
  and measured, 0 for none; default 0.
- jacop.jasat.check: check the propagation invariants of the SAT solver
  at every fixpoint; default false.
- jacop.ls.debug: print why local search rejects moves; default false.
- jacop.ls.verify: check the incremental state of local search (sums,
  counters, windows, element selections, followers) against values
  computed afresh after every step; default false.
- tmp.lattice: print the pruning of LinearEqualities by residue
  classes; default false.
